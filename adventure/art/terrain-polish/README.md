# Town paving edge draft

The transparent 16-tile atlas adds a small, warm stone edging between the existing paving and grass. It is drawn pixel-by-pixel with LibreSprite 1.3, using colors chosen to sit alongside the existing `art/tiles-work/outputs/paving-v2.png` and `grass-v3.png` materials. The existing terrain images are unchanged. `ground-edges.aseprite` is the editable, single-layer atlas, and `public/game/tiles/town-edges.png` is its runtime export. `previews/terrain-sample.png` is an offline composited example; `previews/edge-variants.png` shows all 16 edge combinations against the paving. Both are enlarged with nearest-neighbor sampling.

The atlas contains 4×4 tiles at 32×32 pixels. Tile index is a bitmask of exposed paving edges: north=1, east=2, south=4, west=8; index 0 is fully transparent. `node art/terrain-polish/update-map.mjs` reads the current ground tiles and places the appropriate edges in a separate `ground-edges` layer in the Tiled map without changing any objects. The helper assumes the original atlas tile IDs 1–32 and an edge tileset starting at global ID 33. Run `npm run export:map` afterward. The Phaser scene must preload the atlas and create the overlay layer after the ground layer.

Rebuild the sprite export with `bash art/terrain-polish/build.sh` (LibreSprite 1.3 and FFmpeg required; set `LIBRESPRITE_APP` if the editor is elsewhere). Run `python3 art/terrain-polish/verify.py` for dimensions, alpha, atlas content and map consistency checks. These checks and the offline sample do not constitute in-game or mobile visual approval; the border remains draft art pending actual scene review.
