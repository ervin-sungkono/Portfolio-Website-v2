# NPC drafts

Two original static idle art drafts based on the user-selected town and explorer concept:

- `sprites/guide.png`: welcoming background/about guide.
- `sprites/workshop.png`: skills/workshop guide.
- `sources/`: editable flattened single-frame LibreSprite files.
- `studies/`: generated originals preserved for future refinement.
- `contact.png`: 4× nearest-neighbor review preview.

The game-facing PNGs are 96×128 RGBA with binary alpha. Their visible bounding boxes are `(25, 15, 70, 124)` and `(19, 8, 75, 124)` respectively: both feet baselines are y=124, and neither touches the canvas edges. The images contain no embedded copy or biographical claims. Character visual identity is generated by `image_gen` based on the approved Direction A image, then sized, alpha-cleaned, and exported with LibreSprite 1.3.

These are static, single-frame drafts, not final layered masters or animations. Alpha thresholding, pixel details and style consistency must be reviewed in the game at native scale. Their 96×128 canvases are provisional and should use the same display scale and feet anchor as the explorer sprites.
